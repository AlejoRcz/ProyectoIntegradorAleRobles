# Plataforma Web Colaborativa - Gestión Culinaria

# Requerimientos No Funcionales

## 1. Rendimiento

**RNF1.1** El sistema debe responder en menos de **3 segundos**.  
**RNF1.2** Debe soportar grandes cantidades de usuarios sin fallar.  
**RNF1.3** El tiempo de carga de la página inicial no debe superar los **5 segundos**.

## 2. Seguridad

**RNF2.1** Las contraseñas deben guardarse encriptadas.  
**RNF2.2** Las sesiones expiran tras **2 horas** de inactividad.  
**RNF2.3** El sistema bloquea una cuenta tras **5 intentos fallidos** de inicio de sesión.

## 3. Usabilidad y Accesibilidad

**RNF3.1** El usuario debe poder realizar las funciones principales en máximo **3 clics**.  
**RNF3.2** La interfaz debe ser intuitiva, adaptable a dispositivos móviles y accesible (WCAG 2.1 AA).  
**RNF3.3** Debe contar con modo **claro** y **oscuro**.

## 4. Compatibilidad

**RNF4.1** Debe funcionar correctamente en **Chrome, Edge, Firefox y Safari**.  
**RNF4.2** Debe adaptarse a pantallas desde **360px a 1920px**.  
**RNF4.3** Debe ser usable desde **Windows, Android e iOS**.

## 5. Mantenimiento y Respaldo

**RNF5.1** Disponibilidad mínima del **99% mensual**.  
**RNF5.2** Copias de seguridad automáticas cada **24 horas**.  
**RNF5.3** Las actualizaciones no deben interrumpir el servicio más de **20 minutos** como máximo, además solo si es necesario.

## 6. Privacidad y Cumplimiento Legal
  
**RNF6.1** Mostrar aviso de privacidad visible en todas las páginas.  
**RNF6.2** Usar datos personales solo con autorización del usuario.
