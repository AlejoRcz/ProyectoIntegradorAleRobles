# Plataforma Web Colaborativa - Gestión Culinaria

# Requerimientos Funcionales

## 1. Usuarios y Roles

**RF1.1** El sistema debe permitir registrar, iniciar y cerrar sesión de usuarios.  
**RF1.2** Deben existir tres roles: **Administrador**, **Chef**, y **Usuario Regular**.  
**RF1.3** Los usuarios pueden editar su perfil y foto.  
**RF1.4** Los usuarios pueden seguir a otros y ver sus recetas o actividades.

## 2. Recetas

**RF2.1** Los usuarios pueden crear, editar o eliminar recetas.  
**RF2.2** Cada receta debe tener nombre, ingredientes (con cantidad y costo), pasos, tipo, dificultad, ocasión y presupuesto por porción.  
**RF2.3** Se pueden subir imágenes en las recetas.  
**RF2.4** Los usuarios pueden buscar recetas por nombre, ingredientes o filtros (tipo, dificultad, etc.).
**RF2.5** Los usuarios pueden calificar, comentar y guardar recetas favoritas.  
**RF2.6** Los chefs validan las recetas de otros usuarios.  
**RF2.7** Se pueden crear “versiones derivadas” de recetas manteniendo el crédito al autor.
**RF2.8** El sistema recomienda recetas según intereses/ingredientes del usuario.

## 4. Comunidad y Reconocimiento

**RF4.1** Los usuarios pueden seguir chefs o críticos.  
**RF4.2** El sistema muestra rankings de recetas más populares y mejor valoradas.  
**RF4.3** El sistema puede tener eventos o retos culinarios mensuales.  
**RF4.4** Los usuarios pueden compartir y comentar recetas entre sí.

## 5. Administración

**RF5.1** El administrador gestiona usuarios, categorías y etiquetas de recetas.  
**RF5.2** El administrador modera contenido y revisa reportes de la comunidad.  
**RF5.3** El sistema muestra métricas como número de usuarios, recetas y actividad.
