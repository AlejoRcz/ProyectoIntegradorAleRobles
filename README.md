# ProyectoIntegradorAleRobles
# Plataforma Web Colaborativa - Gestión Culinaria
# Nombre del Sistema: RoblesGastroLab

## 📝 Descripción del proyecto
Este proyecto busca solventar el desarrollo de una plataforma digital colaborativa para chefs y usuarios amantes de la gatronomía. Esta página va a buscar ofrecer diferentes medios y herramientas que enriquezcan la comunidad de usuarios y expertos, al brindar la posibilidad de acceder a recetas detalladas y distribuidas a interés del usuario, además de permitir compartir obras personales con los demás usuarios.

## 🚀 Objetivo General
Crear una solución web integral que facilite la organización culinaria y mejore la experiencia de los usuarios al descubrir, planificar y compartir recetas.

1. (1) Carga y gestiona recetas detalladas incluyendo:
1. (2) Verifica y valida recetas subidas por usuarios avanzados.S
2. (1) Busca recetas mediante filtros avanzados.
2. (2) Guarda recetas favoritas en colecciones personales.

## Convenciones de Nomenclatura y Formato

- **Variables y funciones:** `camelCase`  
  Ejemplo: `calcularCostoPorPorcion`
- **Clases:** `PascalCase`  
  Ejemplo: `RecetaController`
- **Archivos:** `kebab-case`  
  Ejemplo: `user-profile.js`
- **Formato de Código:** 
  No se hace uso de estilos en línea.
  Comentarios claros que mejoren la comprensión.
  Variables con nombres significativos.

## Estrategia de Branches

- `main` → código estable y listo para entrega.  
- `develop` → integración de nuevas funciones antes de subir a main.   
- `fix/` → corrección de errores o ajustes pequeños.  

## Convención de Commits

`[new]` Nueva funcionalidad agregada.
`[update]` Actualización o mejora de código existente. `[fix]` Corrección de errores.
`[delete]` Eliminación de archivos o funciones.
`[docs]` Cambios o mejoras en documentación.
`[style]` Ajustes visuales o de formato.

## 👥 Roles principales del sistema

- **Chef / Experto culinario:** crea, edita y valida recetas.  
- **Usuario regular:** busca, guarda, califica y personaliza recetas.  
- **Administrador:** modera contenido y gestiona métricas del sistema.
